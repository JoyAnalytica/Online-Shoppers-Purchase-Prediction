## 📌 Project Overview

Online retailers want to understand customer purchasing behavior and identify visitors who are likely to complete a purchase.

This project uses the Online Shoppers Purchasing Intention dataset to predict whether a website visitor will generate revenue based on browsing behavior and session-related features.

## 🎯 Project Objectives

- Predict customer purchase intention.
- Analyze online shopping behavior.
- Understand the factors associated with purchasing decisions.
- Apply machine learning and deep learning concepts to a real-world business problem.
- Deploy the prediction application for interactive use.

## 📊 Dataset Information

The project uses the **Online Shoppers Purchasing Intention Dataset**, which contains information about website visitors and their browsing sessions.

**Target variable:** `Revenue`

- `True` — The session resulted in a purchase.
- `False` — The session did not result in a purchase.
